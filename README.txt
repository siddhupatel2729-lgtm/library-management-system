ONLINE LIBRARY MANAGEMENT SYSTEM
================================

Technologies:
- PHP
- MySQL
- HTML/CSS/JavaScript
- XAMPP

SETUP:
1. Install XAMPP.
2. Start Apache and MySQL.
3. Copy the "library_management_system" folder into:
   C:\xampp\htdocs\
4. Open http://localhost/phpmyadmin
5. Create/import the database using database.sql.
   (The SQL file creates the database automatically.)
6. Open:
   http://localhost/library_management_system/

DEFAULT DATABASE SETTINGS:
Host: localhost
Username: root
Password: empty
Database: library_management

FEATURES:
- Dashboard with total books, students and currently issued count
- Books CRUD + search
- Students registration/list/edit + search
- Issue book
- Return book
- Issue/return status filter
- Student ID filter
- MySQL foreign-key relationships
- Responsive UI
